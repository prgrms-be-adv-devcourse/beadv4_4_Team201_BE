# 4.9 예치금 출금 완료

## 설명
사용자는 예치금을 출금할 수 있다

## User Story

> *"내 지갑에 있는 예치금을 내 계좌로 출금하고 싶다"*

## Acceptance Criteria

```gherkin
Feature: 사용자의 지갑에서 예치금 출금

🔹Scenario: 사용자는 예치금을 정상적으로 출금한다
      Given 사용자의 현재 예치금 잔액이 50,000원이다
      And 사용자의 출금 계좌가 등록되어 있다

      When 사용자가 30,000원 출금을 요청하면
      Then 출금 요청이 생성되고 출금 요청의 상태는 REQUESTED 이다

      When 시스템이 출금 가능 여부를 검증하고 처리를 시작하면
      Then 출금 요청의 상태는 PROCESSING 으로 변경된다

      When 외부 이체 처리가 성공적으로 완료되면
      Then 출금 요청의 상태는 COMPLETED 가 된다
      And 사용자의 예치금 잔액은 20,000원이 된다
      And 예치금 출금 내역이 기록된다

🔹Scenario: 예치금 잔액이 부족하여 출금에 실패한다
      Given 사용자의 현재 예치금 잔액이 10,000원이다
      And 사용자의 출금 계좌가 등록되어 있다

      When 사용자가 30,000원 출금을 요청하면
      Then 출금 요청이 생성되고 상태는 REQUESTED 이다

      When 시스템이 출금 가능 여부를 검증하면
      Then 출금 요청의 상태는 FAILED 가 된다
      And 사용자의 예치금 잔액은 변경되지 않는다
      And 예치금 출금 실패 내역이 생성되어 기록된다
      And "잔액이 부족합니다" 오류가 반환된다
```
