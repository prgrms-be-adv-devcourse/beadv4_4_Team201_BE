# 4.12 장바구니 내 금액 수정

## 설명
장바구니에 담은 펀딩 상품에 대해 분담하고자 하는 금액을 수정할 수 있다.

## User Story

> "결제 전에 장바구니에서 상품의 금액을 조정하고 싶다"

## Acceptance Criteria

```gherkin
Feature: 장바구니 내 금액 수정

🔹Scenario: 사용자는 장바구니에 담긴 펀딩 상품의 금액을 정상 범위 내에서 수정할 수 있다
        Given 사용자의 장바구니에 펀딩 상품 A가 담겨 있다
        And 해당 펀딩 상품의 남은 목표 금액은 50,000원이다

        When 사용자가 상품 A의 금액을 20,000원으로 수정하면
        Then 장바구니 내 상품 A의 금액은 20,000원으로 변경된다

🔹Scenario: 펀딩의 참여 금액을 최소 금액 미만으로 입력 시 수정이 제한된다
      Given 사용자의 장바구니에 상품 A가 담겨 있다

      When 사용자가 상품 A의 금액을 1,000원 미만으로 입력하면
      Then 금액 변경은 적용되지 않는다
      And  "펀딩 참여 최소 금액은 1,000원 이상입니다." 오류 메시지가 표시된다

🔹Scenario: 펀딩의 잔액을 초과하는 금액 입력 시 수정이 제한된다
      Given 사용자의 장바구니에 상품 A가 담겨 있다
      And 펀딩의 잔액은 2,000원이다

      When 사용자가 상품 A의 금액을 2,000원을 초과한 금액으로 입력하면
      Then 금액 변경은 적용되지 않는다
      And  "펀딩 잔액을 초과하여 결제할 수 없습니다." 오류 메시지가 표시된다

🔹Scenario: 펀딩 상태가 변경된 경우 금액 수정이 제한된다
        Given 사용자의 장바구니에 펀딩 상품 A가 담겨 있다
        And 해당 펀딩 상품의 상태는 IN_PROGRESS 이다

        When 해당 펀딩 상품의 상태가 COMPLETED 로 변경된 후
        And 사용자가 상품 A의 금액을 수정하려고 하면
        Then 금액 변경은 적용되지 않는다
        And "이미 종료된 펀딩 상품입니다." 오류 메시지가 표시된다
```
