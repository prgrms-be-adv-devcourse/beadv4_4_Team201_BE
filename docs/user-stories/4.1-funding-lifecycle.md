# 4.1 펀딩 라이프사이클 (Funding Lifecycle)

## 설명
누군가의 위시리스트 상품에 대해 누군가 처음으로 결제하면 펀딩 프로젝트가 자동으로 시작된다.

## User Story

> *"친구의 위시리스트 상품을 내가 가장 먼저 결제하면, 별도의 개설 절차 없이 즉시 펀딩이 시작되어 다른 친구들도 참여할 수 있다."*

## Acceptance Criteria

```gherkin
Feature: 첫 결제에 의한 펀딩 시작

🔹Scenario: 위시리스트 상품에 첫 결제가 발생함
  Given 사용자가 위시리스트에 50,000원짜리 상품을 등록한 상태 (Status: PENDING)
  When 친구 A가 10,000원을 결제(첫 결제)를 완료하면
  Then 1. 새로운 Funding 객체가 생성된다 (Status: IN_PROGRESS)
  Then 2. 해당 위시리스트 상품의 상태는 'IN_PROGRESS'으로 변경된다.
  Then 3. 펀딩 종료일은 현재 시간으로부터 +15일로 설정된다. (정책 설정상 변경 가능)
```
