# 4.14 판매자의 판매 상품 수정/삭제

## 설명
판매자는 본인이 등록한 상품의 정보를 수정하거나, 판매 중지(INACTIVE), 삭제할 수 있다.

## User Story

> "판매자는 판매하는 상품 정보를 수정하거나, 판매를 중지하거나, 삭제하고 싶다."

## Acceptance Criteria

```gherkin
Feature: 판매자의 판매 상품 수정/판매 중지/삭제

🔹Scenario: 판매자는 본인 상품의 정보를 수정할 수 있다
        Given 판매자가 본인이 등록한 상품이 존재한다
        And 해당 상품이 삭제되지 않았다 (deletedAt == null)

        When 판매자가 PATCH /api/v2/products/my/{id}로 상품 정보를 수정하면
        Then 상품 정보가 변경된다
        And ProductUpdatedEvent가 발행된다
        And 수정된 정보는 즉시 사용자에게 노출된다

🔹Scenario: 판매자는 진행 중인 펀딩이 없을 때 판매를 중지할 수 있다
        Given 판매자가 본인이 등록한 상품이 존재한다
        And 해당 상품의 상태는 ACTIVE 이다
        And 해당 상품에 진행 중인 펀딩이 존재하지 않는다

        When 판매자가 상품 상태를 INACTIVE로 변경하면
        Then 상품의 상태는 INACTIVE로 변경된다
        And ProductSaleDisabledEvent가 발행된다
        And 해당 상품은 사용자에게 더 이상 노출되지 않는다

🔹Scenario: 진행 중인 펀딩이 있으면 판매를 중지할 수 없다
        Given 판매자가 본인이 등록한 상품이 존재한다
        And 해당 상품의 상태는 ACTIVE 이다
        And 해당 상품에 진행 중인 펀딩이 존재한다

        When 판매자가 상품 상태를 INACTIVE로 변경하려고 하면
        Then 상품의 상태는 변경되지 않는다
        And ProductException(CANNOT_STOP_SALE_DUE_TO_ACTIVE_FUNDING)이 발생한다
        And "진행 중인 펀딩이 있습니다" 오류가 반환된다

🔹Scenario: 판매자는 INACTIVE 상품을 삭제할 수 있다
        Given 판매자가 본인이 등록한 상품이 존재한다
        And 해당 상품의 상태는 INACTIVE 이다

        When 판매자가 DELETE /api/v2/products/my/{id}를 요청하면
        Then product.deletedAt이 현재 시각으로 설정된다
        And ProductDeletedEvent가 발행된다
        And 삭제 성공 응답(204 No Content)이 반환된다

🔹Scenario: ACTIVE 상품은 삭제할 수 없다
        Given 판매자가 본인이 등록한 상품이 존재한다
        And 해당 상품의 상태는 ACTIVE 이다

        When 판매자가 DELETE /api/v2/products/my/{id}를 요청하면
        Then 상품은 삭제되지 않는다
        And ProductException(PRODUCT_NOT_IN_INACTIVE_STATUS)이 발생한다
        And "INACTIVE 상품만 삭제 가능합니다" 오류가 반환된다

🔹Scenario: 본인 소유가 아닌 상품은 수정/삭제할 수 없다
        Given 다른 판매자가 등록한 상품이 존재한다

        When 판매자가 해당 상품을 수정 또는 삭제하려고 하면
        Then 상품은 변경되지 않는다
        And ProductException(PRODUCT_NOT_OWNED)이 발생한다
        And 403 Forbidden 응답이 반환된다
```
