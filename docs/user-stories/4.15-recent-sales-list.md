# 4.15 판매자의 정산 내역 조회

## 설명
판매자는 주문 확정 후 배치 처리된 정산 내역을 조회할 수 있다

## User Story

> "내가 정산받을 금액과 내역을 확인하고 싶다"

## Acceptance Criteria

```gherkin
Feature: 판매자의 정산 내역 조회

🔹Scenario: 판매자는 정산 완료된 내역을 조회한다
      Given 판매자가 판매한 상품의 주문이 확정되었다
      And 정산 배치 작업이 완료되어 settlement_items에 기록되었다

      When 판매자가 GET /api/v1/settlements?page=0&size=10을 요청하면
      Then 정산 내역이 페이징 처리되어 반환된다
      And 각 항목은 orderId 기준으로 그룹화된다
      And 다음 정보가 포함된다:
           | settlementMonth (정산 월) |
           | orderId (주문 ID) |
           | totalSalesAmount (총 판매 금액) |
           | totalSettlementAmount (총 정산 금액) |
           | itemCount (정산 아이템 개수) |
           | status (정산 상태) |

🔹Scenario: 정산 내역이 없는 경우
      Given 판매자가 판매 내역이 없거나 아직 정산이 완료되지 않았다

      When 판매자가 GET /api/v1/settlements를 요청하면
      Then 빈 리스트가 반환된다
      And totalElements는 0이다
      And HTTP 200 OK 응답이 반환된다

🔹Scenario: 페이지네이션이 적용된다
      Given 판매자에게 30건의 정산 내역이 있다

      When 판매자가 ?page=1&size=10을 요청하면
      Then 11번째부터 20번째까지 10건이 반환된다
      And totalElements는 30이다

🔹Scenario: 정산 금액은 수수료가 차감된 금액이다
      Given 판매자가 100,000원 상품을 판매했다
      And 플랫폼 수수료 5%, PG 수수료 3%가 적용된다

      When 정산 배치가 실행되면
      Then totalSalesAmount는 100,000원이다
      And totalSettlementAmount는 92,000원이다 (100,000 * 0.92)

🔹Scenario: 실시간 판매 내역은 조회할 수 없다
      Given 사용자가 방금 상품을 주문했다
      And 아직 주문 확정이 되지 않았다

      When 판매자가 정산 내역을 조회하면
      Then 해당 주문은 목록에 포함되지 않는다
      And 주문 확정 + 배치 실행 후에만 조회 가능하다
```

## 제약사항

- **필터링 미지원**: 현재 구현에는 기간, 상태별 필터 파라미터가 없음
- **정산 완료 데이터만**: 배치 처리된 settlement_items만 조회 가능
- **실시간 조회 불가**: 주문 즉시 확인 불가, 배치 스케줄 대기 필요
