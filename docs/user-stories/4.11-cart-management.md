# 4.11 장바구니 관리

## 설명
사용자는 여러 펀딩 상품을 자신의 장바구니에 담아둘 수 있다

## User Story

> *"누군가의 위시 리스트에 있는 펀딩 상품을 장바구니에 담고 싶다."*

## Acceptance Criteria

```gherkin
Feature: 펀딩 상품 장바구니 관리

🔹Scenario: 사용자는 위시리스트의 펀딩 상품을 장바구니에 담을 수 있다
        Given 친구의 위시리스트에 상품이 존재한다
        And 해당 상품의 펀딩 상태는 PENDING 이다

        When 사용자가 해당 상품을 장바구니에 추가하면
        Then 사용자의 장바구니에 해당 상품이 추가된다
        And 장바구니 항목에는 상품 식별자와 펀딩 상태(IN_PROGRESS)가 저장된다

        OR

        Given 친구의 위시리스트에 상품이 존재한다
        And 해당 상품의 펀딩 상태는 IN_PROGRESS 이다

        When 사용자가 해당 상품을 장바구니에 추가하면
        Then 사용자의 장바구니에 해당 상품이 추가된다
        And 장바구니 항목에는 펀딩 식별자와 현재 펀딩 상태(IN_PROGRESS)가 저장된다

🔹Scenario: 사용자는 장바구니에 담긴 펀딩 상품을 제거할 수 있다
        Given 사용자의 장바구니에 펀딩 상품이 담겨 있다

        When 사용자가 장바구니에서 해당 상품을 제거하면
        Then 장바구니에서 해당 상품 항목은 제거된다

🔹Scenario: 펀딩이 종료된 상품은 장바구니에 담을 수 없다
        Given 친구의 위시리스트에 상품이 존재한다
        And 해당 상품의 펀딩 상태는 COMPLETED 이다

        When 사용자가 해당 상품을 장바구니에 추가하려고 하면
        Then 장바구니에 추가되지 않는다
        And "이미 종료된 펀딩 상품입니다" 오류가 반환된다

        OR

        Given 친구의 위시리스트에 상품이 존재한다
        And 해당 상품의 펀딩 상태는 EXPIRED 이다

        When 사용자가 해당 상품을 장바구니에 추가하려고 하면
        Then 장바구니에 추가되지 않는다
        And "기간이 만료된 펀딩 상품입니다" 오류가 반환된다

🔹Scenario: 펀딩 상태가 변경되면 장바구니 내 항목도 유효성을 잃는다
        Given 사용자의 장바구니에 펀딩 상품이 담겨 있다
        And 해당 상품의 펀딩 상태는 IN_PROGRESS 이다

        When 해당 펀딩 상품의 상태가 IN_PROGRESS → COMPLETED 로 전이되면
        And 해당 장바구니 항목은 결제 대상에서 제외된다

        When 해당 펀딩 상품의 상태가 IN_PROGRESS → EXPIRED 로 전이되면
        And 해당 장바구니 항목은 결제 대상에서 제외된다
```
