# 4.5 결제 취소 및 환불 (Refund)

## 설명
펀딩이 실패한 경우, 참여자의 결제 금액은 자동으로 환불된다.

## User Story

> *"펀딩이 실패하면 내가 결제한 금액을 자동으로 돌려받고 싶다."*

## Acceptance Criteria

```gherkin
Feature: 펀딩 실패 시 자동 환불

🔹Scenario: 펀딩 실패로 인한 환불 처리
  Given 사용자가 펀딩에 20,000원을 결제한 상태이다
  And 해당 펀딩의 상태가 'EXPIRED'이다
  When 환불 처리 로직이 실행되면
  Then 결제 상태는 'REFUNDED'로 변경된다
  And 사용자에게 결제 금액 전액이 반환된다
```
