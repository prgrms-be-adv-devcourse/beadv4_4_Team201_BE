# 4.13 판매자 상품 등록

## 설명
판매자는 상품을 등록 할 수 있다.

## User Story

> *"판매자는 본인이 판매할 상품을 플랫폼에 등록하고 싶다"*

## Acceptance Criteria

```gherkin
Feature: 판매자 상품 등록

🔹Scenario: 판매자는 상품 정보를 입력하여 상품을 등록할 수 있다
        Given 판매자는 관리자에게 판매자 등록 승인을 받았다
        And 판매자가 유효한 상품 정보를 입력했다
          | 항목 | 값 |
          | 상품명 | 무선 이어폰 |
          | 가격 | 50,000원 |
          | 재고 | 100개 |

        When 판매자가 상품 등록을 요청하면
        Then 새로운 상품이 생성된다
        And 상품의 상태는 DRAFT 이다

🔹Scenario: 판매자는 등록된 상품을 검증 완료 후 판매 가능 상태로 전환할 수 있다
        Given 판매자가 등록한 상품이 DRAFT 상태로 존재한다

        When 판매자가 상품을 판매 시작 상태로 전환하면
        Then 상품의 상태는 ACTIVE 로 변경된다
        And 해당 상품은 사용자에게 노출된다

🔹Scenario: 필수 정보가 누락된 경우 상품 등록은 실패한다
        Given 판매자가 상품 등록 화면에 진입해 있다
        And 상품명 또는 가격이 입력되지 않았다 (필수 항목 미입력)

        When 판매자가 상품 등록을 요청하면
        Then 상품은 생성되지 않는다
        And "필수 상품 정보가 누락되었습니다" 오류 메시지가 반환된다
```
