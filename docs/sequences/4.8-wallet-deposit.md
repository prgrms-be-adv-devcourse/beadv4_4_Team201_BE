# 4.8 예치금 충전 완료 - Sequence Diagram

## Diagram

```mermaid
sequenceDiagram
    actor User as 사용자
    participant WalletService as 지갑 서비스
    participant PaymentAPI as 결제 API
    participant WalletDB as 지갑 DB
    participant WalletHistory as 지갑 내역

    Note over WalletDB: 초기 잔액: 20,000원

    %% 성공 시나리오
    User->>+WalletService: 10,000원 충전 요청
    WalletService->>+PaymentAPI: 결제 승인 요청 (10,000원)

    alt 결제 성공
        PaymentAPI-->>WalletService: 결제 승인 완료
        WalletService->>+WalletDB: 잔액 업데이트<br/>(20,000 + 10,000 = 30,000원)
        WalletDB-->>-WalletService: 업데이트 완료

        WalletService->>+WalletHistory: 충전 내역 기록<br/>(+10,000원)
        WalletHistory-->>-WalletService: 내역 저장 완료

        WalletService-->>-User: 충전 성공 응답<br/>(잔액: 30,000원)

    else 결제 실패
        PaymentAPI-->>WalletService: 결제 실패
        deactivate PaymentAPI

        WalletService->>+WalletHistory: 충전 실패 내역 기록
        WalletHistory-->>-WalletService: 내역 저장 완료

        WalletService-->>User: 충전 실패 응답<br/>("결제에 실패했습니다")
        deactivate WalletService
    end

    Note over WalletDB: 성공 시 잔액: 30,000원<br/>실패 시 잔액: 20,000원 (변경 없음)
```

## 주요 흐름

### 성공 시나리오
1. 사용자가 10,000원 충전 요청
2. 결제 API를 통한 결제 승인 요청
3. 결제 승인 완료
4. 지갑 잔액 업데이트 (20,000 + 10,000 = 30,000원)
5. 충전 내역 기록
6. 충전 성공 응답

### 실패 시나리오
1. 사용자가 10,000원 충전 요청
2. 결제 API를 통한 결제 승인 요청
3. 결제 실패
4. 충전 실패 내역 기록
5. 오류 메시지 반환 ("결제에 실패했습니다")
6. 잔액은 변경되지 않음

## 핵심 포인트
- **트랜잭션**: 결제 성공 시에만 잔액 업데이트
- **이력 관리**: 성공/실패 모두 내역 기록
- **원자성**: 잔액 업데이트와 내역 기록은 원자적으로 처리
- **명확한 오류**: 실패 시 명확한 오류 메시지 제공
