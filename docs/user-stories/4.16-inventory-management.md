# 4.16 판매자의 상품 재고 관리

## 설명
판매자는 본인이 등록한 상품의 재고 수량을 조회하고 수정할 수 있다

## User Story

> "판매 중인 상품의 재고를 직접 관리해서 품절이나 과판매를 방지하고 싶다"

## Acceptance Criteria

```gherkin
Feature: 판매자의 상품 재고 관리

🔹Scenario: 판매자는 상품별 재고 수량을 조회할 수 있다
        Given 판매자는 하나 이상의 상품을 등록해두었다

        When 판매자가 상품 관리 페이지에 진입하면
        Then 본인이 등록한 상품 목록이 표시된다
        And 각 상품에는 현재 재고 수량이 함께 표시된다

🔹Scenario: 판매자는 상품의 재고 수량을 수정할 수 있다
        Given 판매자가 상품 관리 페이지에서 상품A를 선택했다
        And 상품A의 현재 재고 수량은 10개이다

        When 판매자가 재고 수량을 15개로 변경하면
        Then 상품A의 재고 수량은 15개로 저장된다
        And 재고 변경 이력이 기록된다

🔹Scenario: 판매자는 재고 수량을 0으로 설정할 수 있다
        Given 판매자가 상품A의 재고를 관리하고 있다

        When 판매자가 상품A의 재고 수량을 0으로 변경하면
        Then 상품A의 상태는 SOLDOUT 로 변경된다
        And 구매자는 해당 상품을 구매할 수 없다

🔹Scenario: 유효하지 않은 재고 수량 입력 시 수정이 제한된다
        Given 판매자가 상품A의 재고를 수정하려 한다

        When 판매자가 재고 수량을 음수로 입력하면
        Then 재고 변경은 적용되지 않는다
        And "유효하지 않은 재고 수량입니다" 오류 메시지가 표시된다

🔹Scenario: 주문 완료 시 재고가 자동으로 차감된다
        Given 상품A의 재고 수량은 5개이다

        When 해당 상품에 대해 주문이 결제 완료 상태가 되면
        Then 상품A의 재고 수량은 1 감소한다
        And 재고 수량이 0이 되면 상품 상태는 품절로 변경된다
```
