# 4.13 판매자 상품 등록 - Sequence Diagram

## Diagram

```mermaid
sequenceDiagram
    actor Seller as 판매자
    participant ProductService as 상품 서비스
    participant SellerService as 판매자 서비스
    participant ProductDB as 상품 DB

    Note over Seller,ProductDB: 시나리오 1: 상품 등록 (DRAFT)

    Seller->>+ProductService: 상품 등록 요청<br/>(상품명, 가격, 재고 등)
    ProductService->>+SellerService: 판매자 권한 확인
    SellerService-->>-ProductService: 판매자 권한 확인 완료

    ProductService->>ProductService: 상품 정보 검증<br/>(필수 항목 확인)

    ProductService->>+ProductDB: 상품 생성<br/>(Status: DRAFT)
    ProductDB-->>-ProductService: 상품 ID 반환

    ProductService-->>-Seller: 상품 등록 성공<br/>(Status: DRAFT)

    Note over ProductDB: 상품 생성 완료<br/>Status: DRAFT<br/>(사용자에게 미노출)

    Note over Seller,ProductDB: 시나리오 2: 판매 시작 (DRAFT → ACTIVE)

    Seller->>+ProductService: 상품 판매 시작 요청<br/>(상품 ID)
    ProductService->>+ProductDB: 상품 조회<br/>(Status: DRAFT)
    ProductDB-->>-ProductService: 상품 정보 반환

    ProductService->>ProductService: 상품 정보 최종 검증

    ProductService->>+ProductDB: 상품 상태 변경<br/>(DRAFT → ACTIVE)
    ProductDB-->>-ProductService: 상태 변경 완료

    ProductService-->>-Seller: 판매 시작 완료<br/>(Status: ACTIVE)

    Note over ProductDB: 상품 상태: ACTIVE<br/>(사용자에게 노출)

    Note over Seller,ProductDB: 시나리오 3: 필수 정보 누락 (실패)

    Seller->>+ProductService: 상품 등록 요청<br/>(가격 누락)
    ProductService->>ProductService: 상품 정보 검증<br/>(필수 항목 확인)

    alt 필수 정보 누락
        ProductService-->>Seller: "필수 상품 정보가 누락되었습니다" 오류
        deactivate ProductService
    end
```

## 주요 흐름

### 1. 상품 등록 (DRAFT)
1. 판매자가 상품 정보 입력 (상품명, 가격, 재고 등)
2. 판매자 권한 확인
3. 상품 정보 검증 (필수 항목 확인)
4. 상품 생성 (DRAFT 상태)
5. 상품 등록 성공 응답
6. DRAFT 상태에서는 사용자에게 미노출

### 2. 판매 시작 (DRAFT → ACTIVE)
1. 판매자가 상품 판매 시작 요청
2. 상품 조회 (DRAFT 상태 확인)
3. 상품 정보 최종 검증
4. 상품 상태를 ACTIVE로 변경
5. 판매 시작 완료 응답
6. ACTIVE 상태에서는 사용자에게 노출

### 3. 필수 정보 누락 (실패)
1. 판매자가 필수 항목 누락된 상태로 등록 요청
2. 상품 정보 검증 실패
3. "필수 상품 정보가 누락되었습니다" 오류 반환
4. 상품은 생성되지 않음

## 핵심 포인트
- **2단계 프로세스**: DRAFT → ACTIVE 단계적 상품 등록
- **권한 검증**: 판매자 권한 확인 필수
- **필수 항목 검증**: 상품명, 가격 등 필수 정보 검증
- **노출 제어**: DRAFT 상태에서는 미노출, ACTIVE 상태에서만 노출
