# 4.4 펀딩 종료일 초과 처리 (Funding Expiration)

## 설명
펀딩 종료일까지 목표 금액을 달성하지 못하면 펀딩은 실패 처리된다.

## User Story

> *"정해진 기간 안에 펀딩이 완료되지 않으면 자동으로 실패 처리되어 혼란이 없었으면 좋겠다."*

## Acceptance Criteria

```gherkin
Feature: 펀딩 기간 만료 처리

🔹Scenario: 펀딩 종료일이 경과함
  Given 목표 금액이 100,000원인 펀딩이 진행 중이다 (Status: IN_PROGRESS)
  And 현재 날짜가 펀딩 종료일을 초과했다
  When 시스템 배치 작업이 실행되면 (매일 00:00 @Scheduled)
  Then 1. 펀딩 상태는 'EXPIRED'로 변경된다
  Then 2. closedAt에 종료 시각이 기록된다
  Then 3. FundingExpiredEvent가 발행된다
  Then 4. 참여자 결제가 자동 환불된다 (OrderEventListener)
  Then 5. 위시리스트 상품의 상태는 'PENDING'로 되돌아간다 (WishlistEventListener)
```
