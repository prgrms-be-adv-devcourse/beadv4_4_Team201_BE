# 4.8 예치금 충전 완료

## 설명
사용자는 결제(PaymentType: DEPOSIT_CHARGE)를 통해 지갑에 예치금을 충전할 수 있다

## User Story

> *"펀딩에 참여하기 위해 내 지갑에 예치금을 충전하고 싶다"*

## Acceptance Criteria

```gherkin
Feature: 사용자의 지갑에 예치금 충전

🔹Scenario: 사용자는 예치금을 정상적으로 충전한다
      Given 사용자의 현재 예치금 잔액이 20,000원이다
      When 사용자가 PaymentType.DEPOSIT_CHARGE로 10,000원 결제를 완료하면
      Then PaymentSucceededEvent가 발행된다
      And PaymentSucceededEventHandler가 WalletService.charge()를 호출한다
      And 사용자의 예치금 잔액은 30,000원이 된다
      And WalletHistory에 CHARGE 타입으로 내역이 기록된다
      And WalletChargedEvent가 발행된다

🔹Scenario: 중복 충전 요청은 차단된다
      Given 사용자가 이미 동일한 orderNumber로 충전을 완료했다
      When 동일한 orderNumber로 재충전이 시도되면
      Then WalletException(DUPLICATED_TRANSACTION)이 발생한다
      And 잔액은 변경되지 않는다

🔹Scenario: 최소 충전 금액 미만은 거부된다
      Given 사용자의 현재 잔액이 20,000원이다
      When 사용자가 500원을 충전하려고 하면
      Then WalletException(CHARGE_AMOUNT_BELOW_MINIMUM)이 발생한다
      And 잔액은 변경되지 않는다

🔹Scenario: 결제가 실패하면 지갑은 변경되지 않는다
      Given 사용자의 현재 예치금 잔액이 20,000원이다
      When 사용자가 10,000원 결제를 시도했으나 결제가 실패하면
      Then PaymentSucceededEvent가 발행되지 않는다
      And WalletService.charge()가 호출되지 않는다
      And 사용자의 예치금 잔액은 변경되지 않는다
      And WalletHistory에 충전 실패 내역이 기록되지 않는다

🔹Scenario: 지갑이 없는 사용자도 충전할 수 있다
      Given 사용자의 지갑이 아직 생성되지 않았다
      When 사용자가 10,000원을 충전하면
      Then 잔액 0원의 새 지갑이 자동 생성된다
      And 충전 후 잔액은 10,000원이 된다
```
