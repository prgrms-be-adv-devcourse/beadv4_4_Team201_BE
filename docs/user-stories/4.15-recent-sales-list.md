# 4.15 판매자의 최근 판매 상품 목록 조회

## 설명
판매자는 본인이 최근에 판매한 상품 목록을 확인할 수 있다

## User Story

> "내가 최근에 어떤 상품이 판매됐는지 한눈에 보고 싶다"

## Acceptance Criteria

```gherkin
Feature: 판매자의 최근 판매 상품 목록 조회

🔹Scenario: 판매자는 최근 판매된 본인 상품 목록을 조회한다
      Given 판매자는 하나 이상의 상품을 판매한 이력이 있다
      When 판매자가 판매 관리 페이지에 진입하면
      Then 최근 판매된 상품 목록이 표시된다
      And 각 상품은 판매일 기준 내림차순으로 정렬된다

🔹Scenario: 최근 판매 상품 목록에는 핵심 정보가 포함된다
      Given 판매자가 최근 판매 상품 목록을 조회한다

      Then 각 상품 항목에는 다음 정보가 포함된다
           | 상품명 |
           | 판매 수량 |
           | 판매 금액 |
           | 구매자 정보 |
           | 판매 일시 |

🔹Scenario: 최근 판매 내역이 없는 경우
      Given 최근 판매된 상품이 존재하지 않는다
      When 판매자가 판매 관리 페이지에 진입하면
      Then"최근 판매된 상품이 없습니다" 메시지가 표시된다

🔹Scenario: 판매자는 조회 기간을 기준으로 목록을 필터링할 수 있다
      Given 판매자가 최근 판매 상품 목록을 조회 중이다

      When 판매자가 조회 기간을 최근 7일로 설정하면
      Then 최근 7일 내 판매된 상품만 목록에 표시된다

🔹Scenario: 판매자는 판매 상태별로 상품을 구분하여 볼 수 있다
      Given 판매자가 최근 판매 상품 목록을 조회 중이다

      When 판매자가 판매 상태 필터를 적용하면
      Then 선택한 판매 상태(결제완료, 배송중, 배송완료)에 해당하는 상품만 표시된다
```
