# 4.12 장바구니 내 금액 수정

## 설명
장바구니에 담은 펀딩 상품에 대해 분담하고자 하는 금액을 수정할 수 있다.

## User Story

> "결제 전에 장바구니에서 상품의 금액을 조정하고 싶다"

## Acceptance Criteria

```gherkin
Feature: 장바구니 내 금액 수정

🔹Scenario: 사용자는 장바구니에 담긴 펀딩 상품의 금액을 정상 범위 내에서 수정할 수 있다 (upsert 방식)
        Given 사용자의 장바구니에 펀딩 상품 A가 담겨 있다
        And 해당 펀딩 상품의 남은 목표 금액은 50,000원이다
        And 상품 가격은 100,000원이다

        When 사용자가 PATCH /api/v2/carts/items로 상품 A의 금액을 20,000원으로 수정하면
        Then Cart.addItem()이 호출되어 기존 항목이 업데이트된다 (UPDATED 반환)
        And 장바구니 내 상품 A의 금액은 20,000원으로 변경된다

🔹Scenario: 장바구니에 없는 상품을 수정 API로 추가할 수 있다
        Given 사용자의 장바구니가 비어 있다

        When 사용자가 PATCH /api/v2/carts/items로 상품 B를 추가하면 (amount: 15,000원)
        Then Cart.addItem()이 호출되어 새 항목이 추가된다 (ADDED 반환)
        And 장바구니에 상품 B가 추가된다

🔹Scenario: 펀딩의 참여 금액을 최소 금액 미만으로 입력 시 수정이 제한된다
      Given 사용자의 장바구니에 상품 A가 담겨 있다

      When 사용자가 상품 A의 금액을 500원으로 입력하면
      Then 금액 변경은 적용되지 않는다
      And 에러 코드 C001 (INVALID_AMOUNT)이 반환된다
      And "참여 금액은 1,000원 이상이여야 합니다" 메시지가 표시된다

🔹Scenario: 펀딩의 잔액을 초과하는 금액 입력 시 수정이 제한된다
      Given 사용자의 장바구니에 상품 A가 담겨 있다
      And 펀딩의 잔액은 50,000원이다

      When 사용자가 상품 A의 금액을 60,000원으로 입력하면
      Then 금액 변경은 적용되지 않는다
      And 에러 코드 C014 (EXCEED_REMAINING_AMOUNT)가 반환된다
      And "참여 금액은 펀딩 잔액을 초과할 수 없습니다" 메시지가 표시된다

🔹Scenario: 상품 가격을 초과하는 금액 입력 시 수정이 제한된다
      Given 사용자의 장바구니에 상품 A가 담겨 있다
      And 상품 가격은 100,000원이다

      When 사용자가 상품 A의 금액을 150,000원으로 입력하면
      Then 금액 변경은 적용되지 않는다
      And 에러 코드 C015 (EXCEED_PRODUCT_PRICE)가 반환된다
      And "참여 금액은 상품 금액을 초과할 수 없습니다" 메시지가 표시된다

🔹Scenario: 펀딩 상태가 변경된 경우 금액 수정이 제한된다
        Given 사용자의 장바구니에 펀딩 상품 A가 담겨 있다
        And 해당 펀딩 상품의 WishlistItemStatus는 IN_PROGRESS 이다

        When 해당 펀딩 상품의 상태가 COMPLETED 로 변경된 후
        And 사용자가 상품 A의 금액을 수정하려고 하면
        Then 금액 변경은 적용되지 않는다
        And 에러 코드 C005 (INVALID_ITEM_STATUS)가 반환된다
        And "상품 상태가 유효하지 않습니다" 메시지가 표시된다
```
