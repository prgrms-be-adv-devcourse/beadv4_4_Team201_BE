# 4.16 판매자의 상품 재고 관리

## 설명
판매자는 본인이 등록한 상품의 재고 수량을 조회하고 수정할 수 있다

## User Story

> "판매 중인 상품의 재고를 직접 관리해서 품절이나 과판매를 방지하고 싶다"

## Acceptance Criteria

```gherkin
Feature: 판매자의 상품 재고 관리

🔹Scenario: 판매자는 상품별 재고 수량을 조회할 수 있다
        Given 판매자는 하나 이상의 상품을 등록해두었다

        When 판매자가 상품 관리 페이지에 진입하면
        Then 본인이 등록한 상품 목록이 표시된다
        And 각 상품에는 products.stock 컬럼의 값이 재고 수량으로 표시된다

🔹Scenario: 판매자는 상품의 재고 수량을 수정할 수 있다 (비관적 락)
        Given 판매자가 상품 관리 페이지에서 상품A를 선택했다
        And 상품A의 현재 재고 수량은 10개이다

        When 판매자가 재고 수량을 15개로 변경하면
        Then ProductService가 findByIdForUpdate()로 비관적 락을 획득한다
        And Product.updateStock(15)이 호출된다
        And 상품A의 재고 수량은 15개로 저장된다
        And ProductStockUpdatedEvent가 발행된다
        And ProductStockHistory가 생성된다 (delta: +5, changeType: MANUAL_SELLER)

🔹Scenario: 판매자는 재고 수량을 0으로 설정할 수 있다
        Given 판매자가 상품A의 재고를 관리하고 있다
        And 상품A의 ProductStatus는 ACTIVE이다

        When 판매자가 상품A의 재고 수량을 0으로 변경하면
        Then 상품A의 stock은 0으로 변경된다
        And ProductSaleDisabledEvent가 발행된다
        And ProductStatus는 ACTIVE를 유지한다 (SOLDOUT 상태 없음)
        And 프론트엔드에서 품절 표시를 처리한다

🔹Scenario: 유효하지 않은 재고 수량 입력 시 수정이 제한된다
        Given 판매자가 상품A의 재고를 수정하려 한다

        When 판매자가 재고 수량을 음수로 입력하면
        Then validateCreation()에서 검증 실패한다
        And 재고 변경은 적용되지 않는다
        And 에러 코드 INVALID_PRODUCT_STOCK이 반환된다
        And "유효하지 않은 재고 수량입니다" 메시지가 표시된다

🔹Scenario: 주문 완료 시 재고가 자동으로 차감된다
        Given 상품A의 재고 수량은 5개이다

        When 해당 상품에 대해 주문이 결제 완료 상태가 되면
        Then Product.decreaseStock(1)이 호출된다
        And validateStockForOrder()로 재고 충분 여부를 확인한다 (5 >= 1)
        And 상품A의 재고 수량은 4개로 감소한다
        And ProductStockUpdatedEvent가 발행된다 (changeType: ORDER_COMPLETED)
        And 재고 수량이 0이 되면 ProductSaleDisabledEvent가 발행된다
```
