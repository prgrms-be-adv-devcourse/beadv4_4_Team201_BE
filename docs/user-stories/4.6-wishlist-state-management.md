# 4.6 위시리스트 상품 상태 관리 (Wishlist State)

## 설명
위시리스트 상품은 펀딩 진행 상황에 따라 상태가 변경된다.

## User Story

> *"내가 등록한 위시리스트가 지금 어떤 상태인지 한눈에 알고 싶다."*

## Acceptance Criteria

```gherkin
Feature: 위시리스트 상품의 상태 변경

🔹Scenario: 펀딩 상태에 따른 위시리스트 상품의 상태 변경
      Given 위시리스트 상품의 상태가 'PENDING'이다
      When 펀딩이 시작되면
      Then 위시리스트 상품의 상태는 'IN_PROGRESS'으로 변경된다

🔹Scenario: 펀딩 목표 달성
      Given 위시리스트 상품의 상태가 'IN_PROGRESS'이다
      When 펀딩 상태가 'ACHIEVED'가 되면
      Then 위시리스트 상품의 상태는 'REQUESTED_CONFIRM'로 변경된다

🔹Scenario: 위시리스트에서 펀딩을 컨펌
        Given 위시리스트 상품의 상태가 'REQUESTED_CONFIRM'이다
        When 펀딩 수령자가 펀딩을 수락하면
        Then 위시리스트 상품의 상태는 'COMPLETED'로 변경된다
        Then 위시리스트에서 대상 상품이 제거된다

🔹Scenario: 위시리스트에서 펀딩을 기한내에 컨펌하지 않음 / 거절함
        Given 위시리스트 상품의 상태가 'REQUESTED_CONFIRM'이다
        When 위시리스트 상품의 상태가 'REQUESTED_CONFIRM'로 변경된지 2주일이 지났다
        Then 위시리스트 상품의 상태는 'PENDING'로 변경된다
        Then 펀딩의 상태는 'CLOSED'로 변경된다
        Then 해당 펀딩의 참여자들에게 결제 환불이 진행된다
        And 결제 상태는 'REFUNDED'로 변경된다
```
