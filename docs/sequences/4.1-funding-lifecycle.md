# 4.1 펀딩 라이프사이클 - Sequence Diagram

## Diagram

```mermaid
sequenceDiagram
    autonumber

    participant User as Friend A
    participant Payment as Payment
    participant Wishlist as Friend B Wishlist
    participant Funding as Funding

    User ->> Payment: 결제 요청 (상품 ID, 10,000원)
    Payment ->> Wishlist: 위시리스트 상품 조회 (Status: PENDING)

    alt 첫 결제인 경우
        Payment ->> Funding: Funding 생성 요청
        Funding ->> Funding: Funding 생성 (Status: IN_PROGRESS)
        Funding ->> Funding: 종료일 설정 (now + 15일)

        Funding -->> Payment: Funding 생성 완료 (fundingId)
        Payment ->> Wishlist: 상품 상태 변경 (PENDING → IN_PROGRESS)
    end

    Payment -->> User: 결제 완료 응답
```

## 주요 흐름

1. Friend A가 위시리스트 상품에 대해 첫 결제를 시도
2. Payment 서비스가 위시리스트 상품 조회 (PENDING 상태 확인)
3. Funding 객체 생성 (IN_PROGRESS 상태)
4. 펀딩 종료일 자동 설정 (+15일)
5. 위시리스트 상품 상태를 IN_PROGRESS로 변경
6. 결제 완료 응답 반환
