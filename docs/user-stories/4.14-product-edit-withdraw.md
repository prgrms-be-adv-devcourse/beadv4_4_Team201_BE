# 4.14 판매자의 판매 상품 수정/철회

## 설명
판매자는 상품을 수정/철회 할 수 있다.

## User Story

> "판매자는 판매하는 상품 정보를 수정하거나 철회하고 싶다."

## Acceptance Criteria

```gherkin
Feature: 판매자의 판매 상품 수정/철회

🔹Scenario: 판매자는 판매 중인 상품의 정보를 수정할 수 있다
        Given 판매자가 본인이 등록한 상품이 존재한다
        And 해당 상품의 상태는 DRAFT / ACTIVE 이다

        When 판매자가 상품의 정보를 수정하면
        Then 상품 정보가 변경된다
        And 수정된 정보는 즉시 사용자에게 노출된다

🔹Scenario: 이미 결제가 발생한 상품은 핵심 정보 수정이 제한된다
        Given 판매자가 본인이 등록한 상품이 존재한다
        And 해당 상품의 상태는 ACTIVE 이다
        And 해당 상품에 대해 결제 완료된 내역이 존재한다

        When 판매자가 상품의 가격 또는 판매 조건을 수정하려고 하면
        Then 상품 정보는 변경되지 않는다
        And "이미 결제가 발생한 상품은 주요 정보를 수정할 수 없습니다" 오류 메시지가 반환된다

🔹Scenario: 판매자는 아직 판매 이력이 없는 상품을 철회할 수 있다
        Given 판매자가 본인이 등록한 상품이 존재한다
        And 해당 상품의 상태는 ACTIVE 이다
        And 해당 상품에 대해 결제 완료된 내역이 존재하지 않는다

        When 판매자가 상품 철회를 요청하면
        Then 상품의 상태는 INACTIVE 로 변경된다
        And 해당 상품은 사용자에게 더 이상 노출되지 않는다

🔹Scenario: 이미 결제가 발생한 상품은 철회할 수 없다
        Given 판매자가 본인이 등록한 상품이 존재한다
        And 해당 상품의 상태는 ACTIVE 이다
        And 해당 상품에 대해 결제 완료된 내역이 존재한다

        When 판매자가 상품 철회를 요청하면
        Then 상품의 상태는 변경되지 않는다
        And "이미 판매된 상품은 철회할 수 없습니다" 오류 메시지가 반환된다
```
