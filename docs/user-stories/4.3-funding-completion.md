# 4.3 펀딩 완료 처리 (Funding Completion)

## 설명
펀딩 금액이 목표 금액에 도달하면 펀딩은 자동으로 완료 상태로 전환된다.

## User Story

> *"펀딩 목표 금액이 모두 모이면, 추가 결제 없이 자동으로 펀딩이 완료되었으면 좋겠다."*

## Acceptance Criteria

```gherkin
Feature: 펀딩 목표 금액 달성 시 자동 완료

🔹Scenario: 펀딩 금액이 목표 금액에 도달함
  Given 목표 금액이 50,000원인 펀딩이 진행 중이다 (Status: IN_PROGRESS)
  And 현재까지 누적 금액이 45,000원이다
  When 사용자 A가 5,000원을 결제하면
  Then 1. 펀딩 상태는 'ACHIEVED'로 변경된다
  Then 2. 펀딩 모금 종료 시간이 즉시 기록된다
  Then 3. 더 이상의 결제는 불가능하다
```
