# 4.2 펀딩 참여 및 결제 (Participate & Payment)

## 설명
여러 사용자가 동시에 펀딩에 참여할 수 있으며, 목표 금액 초과 결제를 방지한다.

## User Story

> *"참여자는 **남은 금액** 내에서 자유롭게 금액을 입력하여 **결제**할 수 있다."*

## Acceptance Criteria

```gherkin
Feature: 펀딩 참여 동시성 제어

🔹Scenario: 목표 금액이 1,000원 남은 상황에서 동시 결제 시도
  Given 목표 금액까지 1,000원 남음
  When 사용자 A와 사용자 B가 동시에 1,000원 결제를 시도하면
  Then 먼저 도착한 요청만 성공 처리된다.
  And 늦게 도착한 요청은 "이미 펀딩이 완료되었습니다" 에러를 반환하고 결제 취소된다.
```
