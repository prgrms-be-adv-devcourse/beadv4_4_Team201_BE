# 4.8 예치금 충전 완료

## 설명
사용자는 예치금을 충전할 수 있다

## User Story

> *"상품을 결제하기 위해 내 지갑에 예치금을 충전하고 싶다"*

## Acceptance Criteria

```gherkin
Feature: 사용자의 지갑에 예치금 충전

🔹Scenario: 사용자는 예치금을 정상적으로 충전한다
      Given 사용자의 현재 예치금 잔액이 20,000원이다
      When 사용자가 10,000원 충전을 요청하고 결제가 성공하면
      Then 사용자의 예치금 잔액은 30,000원이 된다
      And 예치금 충전 내역이 기록된다

🔹Scenario: 결제가 실패하여 예치금 충전에 실패한다
      Given 사용자의 현재 예치금 잔액이 20,000원이다
      When 사용자가 10,000원 충전을 요청했으나 결제가 실패하면
      Then 사용자의 예치금 잔액은 변경되지 않는다
      And 예치금 충전에 실패한 내역이 기록된다
      And "결제에 실패했습니다" 오류가 반환된다
```
