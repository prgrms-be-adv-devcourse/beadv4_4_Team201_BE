# 4.11 장바구니 관리 - Sequence Diagram

## Diagram

```mermaid
sequenceDiagram
    actor User as 사용자
    participant CartService as 장바구니 서비스
    participant WishlistService as 위시리스트 서비스
    participant FundingService as 펀딩 서비스
    participant CartDB as 장바구니 DB

    Note over User,CartDB: 시나리오 1: 펀딩 상품 추가 (PENDING 상태)

    User->>+CartService: 위시리스트 상품 장바구니 추가 요청
    CartService->>+WishlistService: 상품 조회
    WishlistService-->>-CartService: 상품 정보 (펀딩 상태: PENDING)

    CartService->>CartService: 펀딩 상태 검증 (PENDING)

    CartService->>+CartDB: 장바구니 항목 추가<br/>(상품 ID, 펀딩 상태)
    CartDB-->>-CartService: 추가 완료

    CartService-->>-User: 장바구니 추가 성공

    Note over User,CartDB: 시나리오 2: 펀딩 상품 추가 (IN_PROGRESS 상태)

    User->>+CartService: 위시리스트 상품 장바구니 추가 요청
    CartService->>+WishlistService: 상품 조회
    WishlistService->>+FundingService: 펀딩 조회
    FundingService-->>-WishlistService: 펀딩 정보 (상태: IN_PROGRESS)
    WishlistService-->>-CartService: 상품 정보 (펀딩 상태: IN_PROGRESS)

    CartService->>CartService: 펀딩 상태 검증 (IN_PROGRESS)

    CartService->>+CartDB: 장바구니 항목 추가<br/>(펀딩 ID, 펀딩 상태)
    CartDB-->>-CartService: 추가 완료

    CartService-->>-User: 장바구니 추가 성공

    Note over User,CartDB: 시나리오 3: 장바구니 항목 제거

    User->>+CartService: 장바구니 항목 제거 요청
    CartService->>+CartDB: 장바구니 항목 조회
    CartDB-->>-CartService: 항목 정보 반환

    CartService->>+CartDB: 장바구니 항목 삭제
    CartDB-->>-CartService: 삭제 완료

    CartService-->>-User: 제거 성공

    Note over User,CartDB: 시나리오 4: 종료된 펀딩 추가 시도 (실패)

    User->>+CartService: 위시리스트 상품 장바구니 추가 요청
    CartService->>+WishlistService: 상품 조회
    WishlistService->>+FundingService: 펀딩 조회
    FundingService-->>-WishlistService: 펀딩 정보 (상태: COMPLETED)
    WishlistService-->>-CartService: 상품 정보 (펀딩 상태: COMPLETED)

    CartService->>CartService: 펀딩 상태 검증 (COMPLETED)

    CartService-->>-User: "이미 종료된 펀딩 상품입니다" 오류

    Note over User,CartDB: 시나리오 5: 펀딩 상태 변경으로 유효성 상실

    Note over CartDB: 장바구니에 펀딩 상품 존재<br/>(펀딩 상태: IN_PROGRESS)

    FundingService->>FundingService: 펀딩 상태 변경<br/>(IN_PROGRESS → COMPLETED)

    User->>+CartService: 장바구니 조회 / 결제 요청
    CartService->>+CartDB: 장바구니 항목 조회
    CartDB-->>-CartService: 항목 목록 반환

    CartService->>+FundingService: 각 펀딩 상태 검증
    FundingService-->>-CartService: 펀딩 상태: COMPLETED

    CartService->>CartService: 유효성 검증 실패<br/>(펀딩 종료)

    CartService-->>-User: 해당 항목은 결제 대상에서 제외됨<br/>("펀딩이 종료되었습니다")
```

## 주요 흐름

### 1. 펀딩 상품 추가 (PENDING 상태)
1. 사용자가 위시리스트 상품 추가 요청
2. 위시리스트 서비스에서 상품 조회
3. 펀딩 상태 검증 (PENDING)
4. 장바구니에 항목 추가 (상품 ID, 펀딩 상태)
5. 추가 성공 응답

### 2. 펀딩 상품 추가 (IN_PROGRESS 상태)
1. 사용자가 위시리스트 상품 추가 요청
2. 위시리스트 및 펀딩 서비스에서 상품/펀딩 조회
3. 펀딩 상태 검증 (IN_PROGRESS)
4. 장바구니에 항목 추가 (펀딩 ID, 펀딩 상태)
5. 추가 성공 응답

### 3. 장바구니 항목 제거
1. 사용자가 항목 제거 요청
2. 장바구니 항목 조회
3. 장바구니 항목 삭제
4. 제거 성공 응답

### 4. 종료된 펀딩 추가 시도
1. 사용자가 상품 추가 요청
2. 상품 및 펀딩 조회 (상태: COMPLETED)
3. 펀딩 상태 검증 실패
4. "이미 종료된 펀딩 상품입니다" 오류 반환

### 5. 펀딩 상태 변경으로 유효성 상실
1. 장바구니에 펀딩 상품 존재 (IN_PROGRESS)
2. 펀딩 상태 변경 (IN_PROGRESS → COMPLETED)
3. 사용자가 장바구니 조회/결제 요청
4. 각 펀딩 상태 실시간 검증
5. 종료된 펀딩은 결제 대상에서 제외
6. 사용자에게 안내 메시지 표시

## 핵심 포인트
- **상태 검증**: 장바구니 추가 시 펀딩 상태 검증
- **실시간 확인**: 결제 시 펀딩 상태 재확인
- **명확한 오류**: 종료/만료된 펀딩 추가 시도 시 명확한 오류 메시지
- **유효성 관리**: 펀딩 상태 변경 시 장바구니 항목 자동 무효화
